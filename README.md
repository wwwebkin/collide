# collide

совместный редактор кода в браузере.
monaco + yjs по websocket, чат комнаты, справа панелька под общий чат и ии.

попробовать можно тут >> https://collide.webkin.site/

## запуск

на винде проще всего ткнуть `start.bat`
(в первый раз сам сделает npm install и откроет браузер)

или так:

```bash
npm install
npm start
```

открой localhost:3000, скинь ссылку с `?room=...` другу или себе во вторую вкладку. всё синкается.

файл можно кинуть в редактор или через плюсик / `ctrl+o`.
сохранение: `ctrl+s` (в chrome/edge пишет прямо в открытый файл, иначе скачает).

## как устроено

- `server/` express + ws (y-websocket)
- `public/` клиент, без сборки. monaco с cdn, yjs с esm.sh
- `POST /api/ai` если хочешь чтобы ии отвечал по делу. ключ в env, не в репо

## ии

из коробки отвечает заглушкой. если хочешь живое:

```bat
set OPENAI_API_KEY=sk-...
npm start
```

или глянь `.env.example`. ключ в клиент не пихай, иначе все кто скачает проект сядут на твой баланс лол
